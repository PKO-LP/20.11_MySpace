## 3. Критический путь и объяснение зависимостей
- **Критическая цепочка задач:** `T-01 → T-02 → T-03 → T-04 → T-05 → T-06 → T-07 → T-08 → T-09 → T-10`.
- **Почему именно эти задачи критические:** Сначала создаётся словарь планет (`planet_data.py`), без которого невозможно построить 3D-сферы на сцене (`T-05`). Без созданных объектов на сцене нельзя привязать выбор планеты и карточки (`T-06`), а без карточки и идентификатора выбранной планеты невозможно сохранить привязанную к ней заметку (`T-07`). Задержка на любом из этих этапов сдвигает начало тестирования (`T-09`) и итоговую дату выпуска `v1.0` (`31.12.2026`).
- **Некритические подзадачи:** Оформление декоративного звёздного фона или уточнение формулировок в руководстве пользователя можно выполнять параллельно с тестированием без сдвига финального срока.
