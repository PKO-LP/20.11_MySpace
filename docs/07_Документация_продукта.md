## 1. Назначение
Настольное приложение «MySpace» предназначено для студентов, школьников и преподавателей. Оно позволяет в интерактивном 3D-режиме наблюдать движение восьми планет вокруг Солнца, приближать и осматривать каждый объект, изучать справочные карточки и сохранять личные текстовые заметки по каждой планете.

**Примечание:** Размеры планет, радиусы орбит и скорости движения в симуляторе изменены для наглядности и не являются точной физической моделью.

## 2. Системные требования
- Операционная система: Windows 10/11, Linux или macOS с графическим рабочим столом и поддержкой OpenGL 3.0+.
- Интерпретатор: Python 3.11–3.13.
- Зависимости: `ursina==8.3.0`, `panda3d==1.10.16`, `pillow==13.0.0` (устанавливаются из `requirements.txt`).
- Подключение к интернету требуется только на этапе установки пакетов; после установки приложение работает автономно.

## 3. Установка (планируемая инструкция — требует проверки)
1. Склонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com
   cd 20.11_MySpace
   ```
2. Создайте и активируйте виртуальное окружение:
   - Windows (PowerShell):
     ```powershell
     python -m venv .venv
     .venv\Scripts\Activate.ps1
     ```
   - Windows (cmd):
     ```cmd
     python -m venv .venv
     .venv\Scripts\activate.bat
     ```
   - Linux / macOS:
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```
3. Установите зависимости:
   ```bash
   python -m pip install -r requirements.txt
   ```

## 4. Запуск (планируемая команда)
Из корневой папки проекта при активированном окружении `.venv` выполните:
```bash
python src/main.py
```
*(Фактический запуск и скриншоты будут добавлены после завершения разработки в Спринте 2).*

## 5. Управление в приложении (по ТЗ)
- **Левая кнопка мыши (ЛКМ)** — выбор планеты на сцене или нажатие кнопок меню.
- **Правая кнопка мыши (ПКМ) + перемещение мыши** — вращение камеры вокруг выбранного объекта.
- **Колесо мыши** — приближение и отдаление камеры.
- **Пробел** — пауза / продолжение движения планет.
- **Клавиша `R`** — возврат к общему виду Солнечной системы и закрытие карточки.
- **Клавиша `Esc`** — выход из программы.

## 6. Работа с заметками
- При выборе планеты в правой панели отображается поле для ввода заметки (до 160 символов).
- Для сохранения текста необходимо нажать кнопку **«Сохранить»** — данные запишутся в файл `data/notes.txt` в кодировке UTF-8.
- **Важное ограничение:** если выбрать другую планету или закрыть программу без нажатия кнопки «Сохранить», несохранённый текст будет потерян.

## 7. Типичные проблемы и их решение
- **`ModuleNotFoundError: No module named 'ursina'`** — убедитесь, что виртуальное окружение `.venv` активировано перед запуском скрипта.
- **Планета отображается белой сферой** — проверьте наличие файлов текстур в папке `assets/textures/`.
- **Ошибка при сохранении заметки** — проверьте права на запись в каталог проекта и отсутствие блокировки папки `data/`.

## 8. Ограничения модели
- Орбиты круговые, лежат в одной плоскости; гравитационные взаимодействия и спутники планет не моделируются.
- Личные заметки (`data/notes.txt`) исключены из репозитория Git и хранятся только локально у пользователя.
