# Источники изображений и справочных данных

## Изображения для учебной работы
Девять PNG-файлов (`sun.png`, `mercury.png`, `venus.png`, `earth.png`, `mars.png`, `jupiter.png`, `saturn.png`, `uranus.png`, `neptune.png`) созданы процедурно для этого задания. Это условные иллюстрации, а не фотографии или точные карты поверхности. Автор учебного набора разрешает использовать и изменять их в учебных проектах без ограничений.

Исходный прототип предоставлен преподавателем и хранится отдельно в `docs/prototype.png`.

## Справочные сведения
Справочные значения в карточках округлены; источник для сверки: [NASA Science — About the Planets](https://nasa.gov).  
Радиусы орбит, размеры сфер и скорости анимации условные.
