# Ручные проверки MySpace

**Состояние:** проверки № 1–10 и 12 выполнены на рабочем ПК; проверки № 11 и 13 (замер FPS и запуск на другом компьютере) ожидают выполнения.

**Среда проверки:** Windows 10/11 (x64), Python 3.14.7, `ursina==8.3.0`, `panda3d==1.10.16`, `pillow==13.0.0`, разрешение окна `1280 × 720`.

1. **Запуск** — 20.11.2026 → Windows 10/11, Python 3.14.7 → выполнить `.venv/Scripts/python.exe src/main.py` → видны Солнце и восемь планет с изображениями → открылось окно `MySpace`, отображаются Солнце, орбиты, 8 планет с текстурами и кольцо Сатурна → **пройдено**.
2. **Выбор каждой планеты мышью** — 20.11.2026 → Windows 10/11, Python 3.14.7 → кликнуть ЛКМ по каждой из 8 планет в 3D-сцене → выделяется нужный объект, открывается соответствующая карточка, камера удерживает его в центре → каждая из 8 планет подсвечивается, открывается её карточка со справочными данными, камера центрируется на планете → **пройдено**.
3. **Выбор каждой планеты кнопкой** — 20.11.2026 → Windows 10/11, Python 3.14.7 → последовательно нажать кнопки от «Меркурий» до «Нептун» в левой панели → результат совпадает с выбором в сцене → поведение полностью совпадает с кликом мышью по сфере планеты → **пройдено**.
4. **Приближение и отдаление до предела** — 20.11.2026 → Windows 10/11, Python 3.14.7 → прокрутить колесо мыши вперёд и назад до упора на общем виде и при выборе планеты → камера не попадает внутрь объекта; система остаётся доступной для просмотра → приближение останавливается на безопасной дистанции перед сферой, отдаление ограничено общим видом → **пройдено**.
5. **Поворот** — 20.11.2026 → Windows 10/11, Python 3.14.7 → зажать ПКМ на пустом участке сцены и перемещать мышь влево и вправо → обзор поворачивается вокруг текущего центра → камера плавно вращается вокруг Солнца или выбранной планеты → **пройдено**.
6. **Пауза** — 20.11.2026 → Windows 10/11, Python 3.14.7 → нажать кнопку «Пауза» или клавишу `Space`, затем повторно → планеты останавливаются; камера, выбор планет и карточки работают → орбитальное и осевое вращение останавливается, выбор планет, карточки и камера продолжают работать → **пройдено**.
7. **Скорости ×0,5, ×1, ×5, ×10** — 20.11.2026 → Windows 10/11, Python 3.14.7 → поочерёдно нажать кнопки `0.5`, `1`, `5`, `10` в нижней панели → движение меняется; текущий множитель виден → скорость движения планет меняется пропорционально множителю, внизу обновляется подпись `Скорость: x...` → **пройдено**.
8. **Общий вид** — 20.11.2026 → Windows 10/11, Python 3.14.7 → выбрать планету, затем нажать `Общий вид [R]` или клавишу `R` → камера возвращается, карточка закрывается, выделение снимается → панель карточки скрывается, подсветка с планеты снимается, камера возвращается в исходную позицию `(0, 40, -55)` → **пройдено**.
9. **Отсутствующая текстура** — 20.11.2026 → Windows 10/11, Python 3.14.7 → временно переименовать один PNG-файл в `assets/textures/` и запустить приложение → используется заглушка, приложение не закрывается → приложение запустилось без сбоев, планета отобразилась со светлой заглушкой `white_cube` (после проверки файл возвращён на место) → **пройдено**.
10. **Интерфейс 1280 × 720** — 20.11.2026 → Windows 10/11, Python 3.14.7 → проверить читаемость текстов и клики по карточкам/кнопкам поверх планет → текст читается, карточки не обрезаются; элементы интерфейса не пропускают нажатия к планетам → все подписи и карточка читаются чётко, клики и прокрутка колеса над UI не затрагивают объекты 3D-сцены → **пройдено**.
11. **Общий обзор** — *(ожидает выполнения)* → указать модель CPU, объём ОЗУ, видеокарту и измерить частоту кадров (FPS) при запущенной сцене → измерить частоту кадров и записать характеристики ПК → *не выполнено (запланировано перед финальной сдачей)*.
12. **Работа 10 минут** — 20.11.2026 → Windows 10/11, Python 3.14.7 → оставить симулятор запущенным на 10 минут с периодическим переключением планет и скоростей → нет аварийного завершения → приложение проработало 10 минут стабильно без вылетов и зависаний → **пройдено**.
13. **Другой компьютер** — *(ожидает выполнения)* → передать ссылку на репозиторий одногруппнику для клонирования и запуска строго по `README.md` → установка и запуск только по README, без помощи автора → *не выполнено (будет проведено на этапе приёмки с одногруппником)*.

## Дополнительная проверка заметок и известное ограничение
- Сохранение заметки в `data/notes.txt` в кодировке `UTF-8` и её автоматическая загрузка при повторном запуске проверены — **пройдено**.
- **Особенности среды:** В `ursina==8.3.0` на Windows виджет `InputField` отображает ввод с русской раскладки клавиатуры символами `▯`, поэтому при вводе заметок с клавиатуры используется латиница.
